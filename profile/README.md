[Misskey](https://github.com/misskey-dev/misskey) から分かれたフェディバースのサーバー Toneriko と、その部品を開発しています。どれも元のプロジェクトには追従していません。

| リポジトリ | 内容 | ライセンス |
| --- | --- | --- |
| [**toneriko**](https://github.com/toneriko-dev/toneriko) | サーバーと Web クライアント | AGPL-3.0 |
| [**toneriko-script**](https://github.com/toneriko-dev/toneriko-script) | Play・ウィジェット・プラグインのスクリプト言語。AiScript 1.2.1 から分かれた | MIT |
| [**mfm-js**](https://github.com/toneriko-dev/mfm-js) | MFM(投稿の装飾記法)のパーサー。mfm.js 0.26.0 から分かれた | MIT |
| [**slacc**](https://github.com/toneriko-dev/slacc) | 署名と zip の読み取りを Rust で行うモジュール。slacc 0.2.0 から分かれた | MIT |
| [**sugar-high**](https://github.com/toneriko-dev/sugar-high) | コードの色付けに使う構文の解析器。sugar-high から分かれた | MIT |

部品は npm に公開していません。元のプロジェクトの著作権表示は、各リポジトリの `LICENSE` に残しています。
